## 什么叫“速度快又便宜”：先定三个判断标准

速度快由机房线路、带宽大小、有没有严重超售决定；便宜则要拆成首购价和续费价两部分看，这两者经常对不上。很多比价文章只对比首年价格，照着买容易吃亏。

### 首购价便宜，续费价才是真实成本

云服务器的数据一旦部署上去，迁移要重新备案、重新配环境，续费涨价时你基本只能被动接受。举个例子：腾讯云标准型S5 2核2G卖199元/年，贵在“新老同享、续费同价”，用三年就是597元；有些厂商首购99元看着更便宜，续费回到原价后，三年总花费反而更高。

阿里云经济型e的活动价属于新用户专享，续费按官网价格走。下单前先想清楚打算用几年，把“首购价＋每年续费价×年数”这笔总账算出来再决定。

### 带宽决定速度上限，别只盯着CPU和内存

低价款普遍只给1–3M带宽，个别甚至不含公网IP。CPU再强，1M带宽的速度上限就在那里。买之前把带宽当成和CPU同级别的参数来看，后面有一节专门算这笔账。

### 备案和实名是绕不开的前提

大陆机房放网站需要ICP备案，国内厂商的活动价普遍要求实名认证，部分还限新用户或首购用户资格。赶时间开站、或者主要面向境外访客的，可以直接考虑境外节点。

## 1M带宽到底有多慢：一笔账

答案先给：1M带宽的理论下载上限约128KB/s。一张压缩过的网页图片200KB左右，用户打开就要多等一秒多；放软件下载基本没法用。3M约384KB/s，纯文字博客、企业官网够用；5M约640KB/s，图片多一点的站点才比较从容。

所以选配的逻辑是：文字为主的博客、测试环境，1–3M够用；图片密集的站点，要么上5M，要么把图片和静态资源放到对象存储加CDN上分流——阿里云生态里对应OSS和CDN，这部分流量费单独计费，下单前要有数。

## 常见问题

**便宜的云服务器会不会很卡？**
不一定。卡顿主要来自严重超售的共享型主机，大厂入门款和上面列的正规商家，日常建站负载下基本感受不出来。

**首购99元，第二年续费要多少钱？**
活动价通常只覆盖首年，续费按官网原价。各家续费价随机型浮动，下单前先确认续费单价，按“首购价＋续费价×使用年数”算总账再决定买几年。

**国内服务器必须备案吗？**
大陆机房放网站需要ICP备案，购买和享受活动价需要实名认证，部分活动还限新用户。纯测试环境或主要面向境外访客的，可以选香港或海外节点绕开这一步。

**阿里云和腾讯云选哪个？**
单纯建站，两家的入门活动机体验差距不大，比价格和续费政策就行：要同价续费看腾讯云标准型S5（199元/年），要首购价低、镜像市场生态全的看阿里云经济型e。没有标准答案，取决于你打算用几年。

## 下单前最后确认这三件事

1. **资格**：活动价基本限新用户或首购用户，实名认证先做好，资格不符下单时价格会变；
